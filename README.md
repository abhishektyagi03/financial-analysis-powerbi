# 📊 Financial Analysis Dashboard | Power BI

An interactive **Power BI Financial Analysis Dashboard** designed to analyze revenue, transactions, country and regional performance, product trends, and financial insights through KPI cards and dynamic visualizations.

## 📌 Dashboard Preview

![Financial Analysis Dashboard](Dashboard/financial_dashboard.png)

## 🎯 Project Objective

The objective of this project is to transform financial data into an interactive business intelligence dashboard that helps users monitor performance and identify important financial trends.

## 📈 Key KPIs

* 💰 **Total Revenue:** 127.41M
* 📊 **Average Revenue:** 39.04K
* 🔄 **Total Transactions:** 3,264
* 🌍 **Total Countries:** 3,264

> KPI values are based on the dashboard version shown in this project and may change after applying filters or refreshing the data.

## 📊 Dashboard Features

* Revenue analysis by region
* Revenue and average revenue by country
* Product and rank performance analysis
* Quarterly revenue trend analysis
* Monthly revenue and regional comparison
* Interactive KPI cards
* Treemap analysis
* Donut chart analysis
* Area and combo charts
* Detailed financial data table

## 🚀 How to Use

1. Clone or download this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `Financial_Analysis_Dashboard.pbix`.
4. If required, update the dataset path in Power Query.
5. Click **Refresh** to load the latest data.
6. Use the dashboard visuals and filters to explore the financial analysis.
